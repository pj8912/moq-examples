# moq-examples
Media-Over-QUIC (moq) examples


## Source
[moq.dev](https://moq.dev/)


## Languages
- Python
- Typescript

## Install

### Python

> Make sure you've installed uv in your system

```bash
cd moq-python
```


#### Install Dependencies
```bash
uv  sync
```

#### To Run 

In one terminal  run: 
```bash
python publisher.py
```
In a second terminal run: 
```bash
python subscriber.py
```

---

### Typescript

> Install bun in your system

```bash
cd moq-ts
```


#### Install dependencies:

```bash
bun install
```

#### To run:

In one terminal run :
```bash
bun run publisher.ts
```

In second terminal run : 
```bash
bun run subscriber.ts
```
